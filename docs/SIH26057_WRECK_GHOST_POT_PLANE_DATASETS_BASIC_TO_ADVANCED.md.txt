### Use

```text
wreck detection
wreck segmentation
wreck preprocessing
wreck positive examples
natural/background comparison
```

https://umfieldrobotics.github.io/ai4shipwrecks/

```text
shipwreck → wreck
```

## 3.2 GHOST POT — GhostVision / Ghost Pot

### What it contains

Real Side-Scan Sonar imagery collected in Delaware's Inland Bays and Delaware Bay for detecting derelict crab pots ("ghost pots").

The dataset source reports:

```text
6,674 annotated sonar images
consumer-grade Humminbird SSS
bounding-box annotations
```

The current Zenodo package also provides a downloadable archive.

### Use

```text
ghost_pot
derelict fishing gear
fishing-gear detection
real SSS object detection
```

### Source / download

Zenodo:
https://zenodo.org/records/20056679

Hugging Face:
https://huggingface.co/datasets/PINGEcosystem/sss-crab-pot-detection-ds

GitHub:
https://github.com/PINGEcosystem/GhostVision

### Important

```text
ghost_pot ≠ ghost_net
```

Do not label crab pots as ghost nets.

### License

The current Hugging Face dataset card lists:

```text
CC-BY-SA-4.0
```

Verify the current original/source terms before redistribution.

### Why first

This is your strongest directly verified SSS source for the **ghost-fishing-gear** part of the project. citeturn883133search3turn883133search5

# 14. DATA SPLIT

Do not randomly split adjacent sonar frames.

Prefer:

```text
Survey/site A → train
Survey/site B → train
Survey/site C → validation
Survey/site D → final test
```

For combined sources, preserve source/site groups whenever possible.

### Start building NOW with only:

```text

   → WRECK

2. SeabedObjects
   → WRECK + PLANE

3. GhostVision / Ghost Pot
   → GHOST POT
```

Then add:

```text

   → WRECK + PLANE
```

Then advanced:

```text
5. KLSG-II
6. Sonar segmentation derived data
7. Sonar Diffusion
8. DCBD
9. SCTD
10. SCTD 3.0
11. DRISHTI-SSS (as a reference/derived corpus, not blindly as your own)
```

### Final scientific rule

Your model should be able to say:

```text
WRECK
GHOST POT
PLANE
UNKNOWN / NATURAL
```

It should **not** be trained to call:

```text
crab pot → ghost net
ship → plane
plane → wreck
```

unless you have a separate, explicit labeling rule and ground truth that justifies that mapping.

For your SIH problem, the strongest approach is a clean **three-target SSS detector first**, followed by the natural-vs-artificial verification and uncertainty/human-review layers from your main plan.
